Entry for the [The One-Line Laugh](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) bounty on make.fun.

`main.py` writes one funny line to `/output/entry.txt`:

> I bought a standing desk to fix my posture, and now I just slouch vertically.

Bought the gear to fix the habit; the habit won, just upright now. The twist lands on the last two words — "slouch vertically" reframes the whole line.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, deterministic.
